ENTERPRISE AI AUDITING IN PRACTICE

Where Deterministic Code Decouples from the LLM

Language models on their own hallucinate mathematical coordinates, planetary degrees, and Dasa intervals. This project implements a 4-layer pipeline where Python and the Swiss Ephemeris compute exact truth first, leaving the LLM to function strictly as a linguistic narrator.

Python 3.13FlaskpyswissephGoogle GeminiZero-Token CriticSQLite WAL
Source Code ↗ Technical README ↗
✧

1. Classical AI (Base Layer)

Deterministic expert system in Python using the Swiss Ephemeris (pyswisseph) to calculate exact planetary degrees, house cusps, and Vimshottari Dasa intervals. The LLM never computes math.

2. Generative AI (Narrator)

Google Gemini receives only a structured, verified "Fact Pack" alongside retrieved classical slokas. It crafts accessible bilingual narratives (English and Tamil) and speech outputs.

3. Agentic AI & Zero-Token Critic

The orchestrator discovers live Gemini models, handles jitter retry on 404/429 errors, and executes a plain-Python Zero-Token Critic that intercepts hallucinations and triggers targeted revisions (max 2 retries).

Customer Clusters & Strategic Actions (From Dissertation Presentation)

Segmentation derived through Recency, Frequency, and Monetary (RFM) K-Means clustering:

1. Champions Highest spend and frequency. Action: Reward with VIP loyalty programs.
2. Loyal Customers Consistent high spend. Action: Upsell and cross-sell higher value tiers.
3. Potential Loyalists Moderate activity. Action: Nurture with personalized recommendations.
4. At Risk Declining engagement. Action: Win-back campaigns and targeted discounts.
5. Lost Customers Longest inactivity. Action: Low-cost, automated re-engagement outreach.
